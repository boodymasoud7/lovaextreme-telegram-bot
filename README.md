# 🤖 دليل تشغيل بوت المبيعات الخاص بـ LOVAEXTREME

يوفر هذا البوت واجهة تفاعلية لمشتركي تليجرام لعرض الأسعار، وسائل الدفع، رابط تنزيل الإكستنشن، ودليل التثبيت، مع إمكانية توليد السيريالات بنقرة زر للأدمن.

---

## 🛠️ خطوات التشغيل

1. **إنشاء البوت في تليجرام:**
   - افتح تليجرام وابحث عن `@BotFather`.
   - أرسل `/newbot` واتبع التعليمات للحصول على **API TOKEN**.

2. **تجهيز وتعديل البيانات في `config.py`:**
   - افتح `telegram_bot/config.py`.
   - ضع الـ `BOT_TOKEN` الخاص بك.
   - ضع رقم الـ Telegram ID الخاص بك في `ADMIN_IDS`.
   - عدّل أرقام وحسابات الدفع (فودافون كاش - إنستا باي - USDT).

3. **تثبيت المكتبة والتشغيل:**
   ```bash
   pip install -r requirements.txt
   python bot.py
   ```

---

## 🔑 الأوامر المتاحة للأدمن:

- `/genserial <days> <plan>` - توليد سيريال جديد للمشتري.
  - مثال توليد سيريال شهري: `/genserial 30 monthly`
  - مثال توليد سيريال سنوي: `/genserial 365 yearly`
  - مثال توليد سيريال مدى الحياة: `/genserial 0 lifetime`
